SIZES

  Every logo file is 64 mm tall. 64 mm is the mark's own master size, so
  nothing is rescaled on the way out and the wordmarks sit at the dimensions
  they were drawn at. Width follows from the master ratios; never respace a
  lockup by hand.

  Every print file is drawn at trim plus 3 mm bleed on each edge, at one user
  unit to the millimetre. A business card is therefore 96 x 60 mm on a 90 x 54
  trim. Artwork that sits on a trim edge is already carried out into the bleed.


THE GUIDES LAYER

  Each print file carries a layer called "guides" holding three rectangles:

    teal, dashed    the bleed edge, at the outside of the canvas
    black, solid    the trim, where the sheet is cut
    red, dashed     the safety margin, 8 mm inside the trim

  Delete that layer before sending anything to press. It is there to be read,
  not printed.


THE .AI FILES

  These are PDF-compatible Illustrator files, which is what an .ai file has
  been under the hood since Illustrator 9. Open them in Illustrator normally.
  Paths are paths, not a traced bitmap, and Helvetica Neue is embedded as a
  subset, so the type stays live and still sets correctly on a machine that
  does not have the font installed.


COLOURWAYS

  Light        full colour on the warm cream ground. The default.
  Dark         the four families relit for a dark ground.
  Dark Mono Gold   one metal at four depths, for ceremonial use.

  Full colour needs a light ground to separate, so it has no white or gold
  variant. On coloured or dark stock use the monocolor artwork reversed.
